What is ε-Closure?

The ε-closure of a state is the set of all states reachable from that state using zero or more ε-transitions.

DFS

Algorithm

The calculator uses graph traversal with a stack to explore all reachable states through ε-transitions.

O

Complexity

The graph traversal takes O(V + E) time for each state, where V represents states and E represents transitions.
